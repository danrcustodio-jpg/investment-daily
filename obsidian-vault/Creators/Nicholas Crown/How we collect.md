## Share a browser (your machine)

The full last-month TikTok grid is easiest from **your** logged-in browser (captcha/rate-limit is weaker):

1. In Cursor Desktop, start a session that can use the computer/browser on **your** PC.
2. Open [tiktok.com/@nicholas_crown](https://www.tiktok.com/@nicholas_crown) → **Videos** → **Latest**.
3. Ask the agent to open each clip from ~the last 30 days, transcribe, and drop a note under `Creators/Nicholas Crown/TikTok/` using the template below.

Do not paste Crown Macro paid-issue text into the vault.
