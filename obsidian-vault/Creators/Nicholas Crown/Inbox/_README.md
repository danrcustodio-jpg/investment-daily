# Transcript inbox

Drop **your** recordings of public clips you already watched (Fireflies, Otter, TikTok captions, phone voice memo + transcribe). Then tell the agent: **process inbox**.

## File name

`YYYY-MM-DD-short-slug.md`  
Example: `2026-08-20-vix-over-10.md`

## What to include

Paste into a new note (or use [[Templates/Fireflies drop]]):

- TikTok URL if you have it
- Date you watched / video date
- Raw transcript (messy is fine)
- Anything you heard that the app missed

## What happens next

The agent turns each drop into a structured note under `Creators/Nicholas Crown/TikTok/`, updates [[Creators/Nicholas Crown/TikTok/Index]], and only then new glossary terms. Raw files can stay here or you can delete them after processing.

## Do not drop

Paid **Crown Macro Letter** issues, subscriber PDFs, or anything you did not have a legitimate right to record.
